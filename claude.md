AI-хакатон: «AI-оператор для бизнеса»
Длительность: 1 час
Формат: 2 команды, одинаковое задание, соревнование
Кейс
Пекарня «Non Uyi» в Ташкенте получает в Telegram около 100 сообщений в день на русском, узбекском и вперемешку. Среди них заказы, вопросы о ценах, жалобы и спам.
Владелец не успевает всё читать, путает заказы и теряет клиентов.
Ваша задача: сделать веб-приложение, которое с помощью LLM API разбирает входящие сообщения и превращает их в понятные данные для владельца.
Что должно работать
Классификация. Каждое сообщение получает одну категорию: order, question, complaint или spam.
Извлечение данных. Из заказа достаются товары, количество, адрес и время. Модель возвращает строгий JSON, приложение его парсит.
Черновик ответа. Для заказов и вопросов генерируется вежливый ответ на том же языке, на котором написал клиент.
Эскалация. Жалобы выделяются красным и не получают автоответ, их разбирает человек.
Дашборд. Таблица заказов и счётчики по категориям.
Формат ответа модели
{
  "category": "order",
  "language": "ru",
  "items": [
    { "product": "самса", "quantity": 10 }
  ],
  "address": "Юнусабад 4-квартал, дом 12",
  "time": "завтра 09:00",
  "reply": "Здравствуйте! Ваш заказ принят..."
}
Если данных нет, поле должно быть null, а не выдуманным.
Технические требования
HTML / CSS / JavaScript, приложение работает в браузере
Можно пользоваться любыми AI-инструментами для написания кода
Каждый участник должен уметь объяснить любую часть кода
Приложение не должно падать, если модель вернула некорректный JSON или API ответил ошибкой
Стартовый код (Gemini API)
const API_KEY = "ВАШ_КЛЮЧ"; // выдаст организатор
const MODEL = "gemini-2.5-flash"; // уточните актуальное название модели в Google AI Studio

async function askAI(prompt) {
  const url = `https://generativelanguage.googleapis.com/v1beta/models/${MODEL}:generateContent?key=${API_KEY}`;

  const response = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      contents: [{ parts: [{ text: prompt }] }],
      generationConfig: { responseMimeType: "application/json" }
    })
  });

  if (!response.ok) {
    throw new Error(`API error: ${response.status}`);
  }

  const data = await response.json();
  return data.candidates[0].content.parts[0].text;
}

// Пример
askAI("Верни JSON: {\"hello\": \"world\"}")
  .then(text => console.log(JSON.parse(text)))
  .catch(err => console.error(err));

Важные условия

Сардор: API должен возвращать результат или понятную ошибку. Для хакатона можно использовать ключ через .env.local, но не публиковать его в GitHub. Для реального приложения API лучше вызывать через сервер.

Фирдавс: промпт должен работать с русским, узбекским и смешанными сообщениями.

Бехруз: отсутствующие данные записывать как null, жалобам не генерировать автоответ.

Камрон: жалобы показывать красным, заказы — в таблице, категории — в статистике.

Баходир: соединить все компоненты, проверить 20 тренировочных сообщений и ошибки API.

Главное: все пятеро могут работать одновременно над разными файлами. Перед началом договоритесь о едином формате JSON, чтобы при объединении React-проекта не возникли конфликты.
