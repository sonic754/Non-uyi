## Проверка через Gemini

`gemini-client.js` позволяет проверять промпт из Node.js. Ключ читается из
локального `.env`, исключённого из Git, и передаётся только в заголовке запроса.
Модель: `gemini-3.1-flash-lite`, её можно изменить через `GEMINI_MODEL`.
Запуск: `npm run evaluate:smoke` для одного примера, `npm run evaluate` для всех 29.
Отчёт `evaluation-results.json` локальный и также исключён из Git.
При HTTP-ошибке прогон останавливается, показывая количество завершённых примеров.
Это серверный клиент для проверки; его нельзя импортировать в браузерный код.

Протокол: [Gemini generateContent](https://ai.google.dev/api/generate-content).

Модуль `ai-prompt.js` готовит промпт для четырёх категорий и определения языка.
Он не вызывает API. Ключ и обработка сетевых ошибок относятся к части Сардора.

## Подключение

В существующей функции `askAI` используйте промпт вместо исходного сообщения:

```js
import { buildClassificationPrompt, parseClassificationResponse } from './ai-prompt.js';

try {
  const text = await askAI(buildClassificationPrompt(message));
  const classification = parseClassificationResponse(text);
  // Передать classification в обработку Бехруза и состояние интерфейса.
} catch (error) {
  // Показать ошибку для этого сообщения и оставить возможность повторить запрос.
}
```

Для HTML без сборщика используйте `<script type="module">`. В React импорт
работает как обычный ES-модуль. Экспорт `CLASSIFICATION_SCHEMA` — стандартная
JSON Schema для контракта; она не подключена к конкретной версии Gemini SDK.

Возвращаются только `category` и `language`. Язык: `ru`, `uz`, `mixed` либо
`null`, если определить его невозможно. Бехруз добавляет `items`, `address`,
`time`, `reply` до формирования полного JSON из задания. Для complaint и spam
черновик ответа должен оставаться null; смешанный язык требует учёта исходного
текста при генерации ответа.

## Как объяснить решение

Классификация основана на намерении: вопрос о цене остаётся question, конкретная
просьба купить становится order. Жалоба на выполненный заказ приоритетнее
просьбы о замене. Узбекская кириллица и русская транслитерация поддерживаются
правилами промпта; название изделия или адрес не считается вторым языком.

Исходное сообщение сериализуется в JSON как данные. Промпт запрещает выполнять
вложенные команды. Это уменьшает риск prompt injection, но не гарантирует
защиту: результат модели проверяется отдельно. Код не подменяет ошибки AI
выдуманной классификацией.

## Проверка

`npm test` проверяет контракт ответа, обработку повреждённого JSON, лишних полей
и сериализацию недоверенного текста. Ключ API не требуется.

`prompt-evaluation.json` содержит 29 примеров с ожидаемыми категориями и языками,
включая адаптированные 20 примеров задания и сложные случаи. Отправляйте их через
`askAI(buildClassificationPrompt(example.message))`, сравнивайте оба поля с
ожидаемыми. Это набор для оценки модели, а не подтверждённые результаты Gemini.
Реальная точность и устойчивость требуют прогона с ключом организатора.
